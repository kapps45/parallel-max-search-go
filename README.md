# ⚡ Parallel Maximum Search

Небольшой Go-проект, демонстрирующий сравнение последовательного и параллельного поиска максимального значения в большом массиве целых чисел.

Программа генерирует набор случайных данных, после чего вычисляет максимум двумя способами: последовательно и с использованием нескольких goroutines. В конце выводятся результаты и время, затраченное на вычисления.

## 🔍 Что реализовано

- 🎲 Генерация большого набора случайных положительных чисел
- 🔎 Последовательный поиск максимального значения
- ✂️ Разделение массива на несколько частей
- ⚡ Параллельная обработка частей с помощью goroutines
- 🔄 Синхронизация завершения задач через `sync.WaitGroup`
- ✅ Сравнение результатов двух алгоритмов
- ⏱️ Измерение времени выполнения каждого подхода

Количество элементов и число параллельных частей задаются константами в `main.go`.

## 🧩 Основная логика

Последовательный вариант проходит по всему массиву и последовательно сравнивает элементы.

Параллельный вариант разбивает исходный массив на несколько сегментов. Для каждого сегмента запускается отдельная goroutine, которая ищет локальный максимум. После завершения всех задач найденные значения дополнительно сравниваются между собой.

Такой подход позволяет на практике изучить работу конкурентного выполнения в **Go** и оценить его влияние на обработку больших объёмов данных.

## 🧪 Тестирование

Тесты покрывают основные варианты работы программы:

- 🎲 Генерацию массивов разного размера
- ⚠️ Обработку нулевого и отрицательного размера
- 📭 Поиск максимума в пустом массиве
- 🔢 Работу с одним и несколькими элементами
- 📍 Случаи, когда максимум находится в начале, середине или конце массива
- 🔁 Обработку одинаковых значений
- ⚖️ Сравнение результата последовательного и параллельного поиска
- 📊 Проверку работы на больших массивах

Для проверок используется библиотека **Testify**.

Запуск всех тестов:

    go test ./...

Подробный вывод:

    go test -v ./...

## 🚀 Запуск

Для запуска программы выполните:

    go run main.go

После запуска приложение генерирует массив из `100 000 000` элементов и выводит время поиска максимума последовательным и параллельным способами.

## 🎯 Цель проекта

Практика конкурентного программирования на **Go**: работа с goroutines и синхронизацией, разбиение больших наборов данных на независимые задачи и сравнение последовательного и параллельного выполнения.
